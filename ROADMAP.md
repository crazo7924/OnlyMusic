# OnlyMusic Roadmap

This roadmap is based on the current app direction, the repository's existing feature set, and the priorities recommended for turning OnlyMusic into a more complete Android music experience.

## Priority 1 — Core playback quality

### 1. Queue and playback controls
- Add repeat, shuffle, and queue management
- Support reordering the current queue
- Allow removing tracks and saving queue snapshots
- Add "Up Next" panel and smarter playback flow

### 2. Background playback and media controls
- Add lock-screen / notification controls
- Integrate Android media session support
- Improve mini-player behavior and consistent playback state
- Support audio focus and resume-after-interruption handling

### 3. Playback reliability improvements
- Better error handling for failed tracks or network issues
- Graceful fallback behavior when upstream content changes
- More descriptive playback state messaging

## Priority 2 — Personalization and library organization

### 4. Favorites and browsing improvements
- Track favorite songs and artists
- Create a proper library section with recently played and favorites
- Add album/artist browsing pages
- Support persistent listening history

### 5. Playlist management
- Create and edit playlists
- Add smart playlists based on listening behavior
- Allow playlist export/import
- Maintain playback state across sessions

### 6. Better metadata and discovery
- Show richer track metadata and artwork
- Add track, artist, and album pages
- Improve search filtering by artist, album, genre, and duration

## Priority 3 — Offline and discovery features

### 7. Offline playback support
- Download or cache favorite tracks when supported
- Add storage management and offline mode controls
- Show cache status and download quality settings

### 8. Search and recommendation improvements
- Add search suggestions and recent searches
- Add recommendations based on listening habits
- Introduce mood or genre-based mixes

## Priority 4 — UX and polish

### 9. Visual polish and personalization
- Dynamic color themes based on album artwork
- Improved Now Playing screen
- Compact player mode and layout refinements
- Better animated transitions

### 10. Accessibility and usability
- Screen-reader support improvements
- Better large-touch targets and gesture interactions
- Improved keyboard and navigation support
- More consistent behavior across screen sizes

## Recommended implementation order

1. Queue + playback controls
2. Background playback + media controls
3. Offline cache/download support
4. Favorites + playlists + history
5. Search improvements + recommendations
6. Visual polish and theming
7. Metadata, lyrics, and richer library pages
8. Accessibility and final UX refinements

## Proposed milestone structure

### Milestone 1: Playback foundation
- Repeat / shuffle / queue controls
- Better playback state handling
- Media session integration

### Milestone 2: Library and personalization
- Favorites, history, and playlists
- Artist/album browsing
- Search filters and recommendations

### Milestone 3: Offline and polish
- Download/caching support
- Visual refresh and theme improvements
- Accessibility and final UX pass

## Issue map

The following enhancement themes are recommended for tracking in the project:

- Queue and playback controls
- Background playback and notifications
- Offline listening support
- Favorites, history, and playlists
- Search suggestions and recommendations
- Rich metadata and library organization
- Theming and visual polish
- Accessibility refinement

These should be tracked as GitHub issues and linked to the "OnlyMusic" project board for milestone planning.
